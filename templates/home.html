POST /predict_api Single or batch prediction
cURL Example 
curl -X POST http://localhost:5000/predict_api \
  -H "Content-Type: application/json" \
  -d '{
    "age": 28,
    "sex": "male",
    "bmi": 33.0,
    "children": 3,
    "smoker": "no",
    "region": "southeast"
  }'
Python Example 
import requests

response = requests.post(
    "http://localhost:5000/predict_api",
    json={
        "age": 28, "sex": "male", "bmi": 33.0,
        "children": 3, "smoker": "no", "region": "southeast"
    }
)
print(response.json())
# {"status": "success", "prediction": 5765.23, ...}
